- Fixed `:autocomplete` going dead after a completion source threw (#430). A sync source's throw
  escaped the trigger, and an async source's throw failed the editor's coroutine scope, so no async
  completion query ran again in that editor. Each source's failure is now reported through
  `logException` (the `exceptionSink` facet) and treated as no result: the other sources' options
  still show and the next trigger queries again. Cancellation still propagates.
