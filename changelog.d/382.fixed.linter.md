- Fixed `linter()` in `:lint` so it runs like `@codemirror/lint` 6.9.5 (#382). The plain
  `linter(LintSource)` had no timer: after typing stopped, its source never re-ran until some other
  transaction arrived, so diagnostics stayed stale. Every linter now runs once the document has
  been idle for the delay, including the first run. Several `linter()` extensions no longer
  overwrite each other's diagnostics. They share one configuration, run together, and their
  diagnostics are shown as one list, using the longest delay any of them sets. A source that is
  slow or fails no longer holds back the others for more than 200 ms. `forceLinting` now only
  hurries a run that is already pending, as upstream does.
