- Fixed `:view` callbacks run on the editor's coroutine scope crashing the app when they threw
  (#431). A throwing `hoverTooltip` source (async or sync), `onChangeAsync`/`onSelectionAsync`
  callback, or `onSave` handler reached the coroutine uncaught-exception handler, which crashes the
  app on Android; a throwing `onSave` handler also cancelled the editor's scope. Each failure is now
  reported through `logException` (the `exceptionSink` facet), as upstream does for hover sources:
  no tooltip is shown, the next hover or change runs normally, and the other save handlers still
  run. Cancellation still propagates.
