- `Tree.resolve` and `Tree.resolveInner` now remember their last result and start the next query
  from it, as `@lezer/common`'s `CachedNode`/`CachedInnerNode` do, so nearby lookups don't
  descend from the root each time (#330). On a 200 KB JavaScript file, a line-by-line
  `resolveInner` went from about 380–540 ns to 130–210 ns per call, and `resolve` from about
  410–490 ns to 100–165 ns.
