- Snippet fields that the template names more than once are linked, as in
  `@codemirror/autocomplete` 6.20.1 (#393). Every copy of the field is selected, so typing edits
  them all; the JavaScript `for` snippet's three `${index}` copies now change together. The cursor
  may be in any copy without ending the snippet.
- **API change:** `SnippetField(name, from, to)` is now `SnippetField(name, ranges)`, where each
  `SnippetRange(from, to)` is one copy of the field in template order. Code that read
  `field.from`/`field.to` should read `field.ranges.first()` for the first copy, or iterate
  `field.ranges`.
