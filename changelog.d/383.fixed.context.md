- Fixed `:autocomplete` completion helpers that disagreed with `@codemirror/autocomplete` 6.20.1 (#383):
  `CompletionContext.matchBefore` only matched a token at the start of a line, so `completeFromList`
  and `completeAnyWord` never fired after the first word; `tokenBefore`/`ifIn`/`ifNotIn` skipped a
  node containing the cursor, so `ifNotIn(["String"])` completed inside strings; `completeFromList`
  ignored non-word label characters (`@me` + `@media` inserted `@@media`); `completeAnyWord` dropped
  one-character prefixes, non-ASCII words and repeats of the typed word; and `insertCompletionText`
  threw or misplaced the cursor when the inserted text contained `\r\n`.
