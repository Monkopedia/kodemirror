- Fixed `SelectionRange.eq(other, includeAssoc = true)` in `:state`, whose condition was inverted:
  it now compares `assoc` only for cursors, as `@codemirror/state` 6.5.4 does. A transaction
  that changes only a cursor's `assoc` or `bidiLevel` is no longer discarded: `EditorState`
  only reuses the old state object when the new selection is identical in every field (#384).
