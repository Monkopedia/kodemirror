- `:language` API changes for upstream parity (#450): `bracketMatchingHandle` is now `NodeProp<(SyntaxNode) -> SyntaxNode?>`,
  upstream's shape: it returns the part of the node that acts as the bracket handle, instead of a
  `MatchResult`. Callers that attached the old function type must return the handle node instead.
  `foldable` gains an optional `lineEnd` parameter (source compatible; recompile).
  `matchBrackets(state, pos, -1)` now means the bracket *ending* at `pos`; callers that passed
  `pos - 1` for the bracket before the cursor must pass `pos`.
  `getIndentation` returns null for a position past the end of the current syntax tree, as
  upstream does; `insertNewlineAndIndent` then keeps the line's existing indentation.
