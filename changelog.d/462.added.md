- Added `MountedTree.bracketed`, recorded from `NestedParse.bracketed` when `parseMixed` mounts
  a tree (#462). This is a binary-incompatible change on the JVM: the three-argument
  `MountedTree` constructor and `copy` now take a fourth `bracketed` parameter, which defaults
  to `false`. Kotlin source that calls them compiles unchanged, but Kotlin and Java callers
  built against 0.3.x must be recompiled.
