- Fixed `SyntaxNode.cursor()` in `:lezer-common` returning a cursor on the tree root instead of
  on the node (#448). Every non-root node's `cursor()`, and therefore `getChild`/`getChildren`,
  looked at the root's children, so HTML completion offered nothing after `<div></`, every tag
  inside `<ul>`, and no values for `<input type=`. Checked against `@lezer/common` on ~15,000 nodes
  of HTML, JavaScript and CSS trees (tree- and buffer-backed, including mounted languages), and
  against `@codemirror/lang-html` completion on 24 inputs.
