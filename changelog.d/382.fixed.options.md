- Wired up three `:lint` options that were declared but never read (#382), matching
  `@codemirror/lint` 6.9.5. `LintConfig.markerFilter` now chooses which diagnostics are kept
  (underlined, counted, listed and navigated), and filters from several configs compose. The lint
  gutter still shows the unfiltered diagnostics, as upstream does. `LintConfig.autoPanel` now opens
  the panel when diagnostics are set and closes it when they are cleared or edited away.
  `LintGutterConfig.hoverTime` now delays the gutter tooltip.
- A lint configuration change that does not touch the document (for example reconfiguring a
  compartment) no longer cancels a lint run already in flight (#382). Upstream lets that run's
  result land and lints again after the delay.
