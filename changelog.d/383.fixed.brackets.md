- Fixed `:autocomplete`'s `closeBrackets` and `deleteBracketPair` diverging from
  `@codemirror/autocomplete` 6.20.1 (#383), by porting upstream's `insertBracket` logic: a quote
  typed after a word is no longer doubled (`don''`), `(` typed over a selection wraps it, a `)` is
  only overtyped when the extension inserted it, and every cursor gets a closing bracket.
  `deleteBracketPair` now leaves a non-empty selection alone and deletes the pair at every cursor
  instead of only the main one. `insertBracket` returns a plain insertion where upstream returns
  `null`.
