- Fixed fast typing doubling text on desktop (#480): typing `field` with two keystrokes in one
  frame produced `fifiefielfield`. The hidden input field only takes back the editor's emptied
  value when it next recomposes, so a second edit in the same frame was reported against the
  previous keystroke's text and entered again. Edits the field makes before it has caught up
  are now restated against the editor's own value. This also covers typed text with no key
  press of its own (Alt/AltGr characters, dead keys, input-method commits).
