- Fixed `nextDiagnostic` and `previousDiagnostic` (F8) in `:lint` to behave like
  `@codemirror/lint` 6.9.5 (#382). They now select the whole diagnostic range rather than placing
  a cursor at its start. `nextDiagnostic` from inside a diagnostic now selects that diagnostic
  instead of skipping to the next one. Both return `false` when there is nothing to move to,
  including when wrapping would reselect the current diagnostic. They no longer tag the
  transaction with a `select.lint` user event, which upstream does not do either.
