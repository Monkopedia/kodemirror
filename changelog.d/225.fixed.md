- `asyncCompletionSource` now works on wasmJs (#225). Before, every call threw
  `UnsupportedOperationException`. In the editor, the completion plugin now runs the wrapped suspend
  source on the editor's coroutine scope on every platform, as it runs `asyncOverride` sources, so
  on JVM and native it no longer blocks the UI thread either. Calling the returned function directly
  still blocks until the source answers on JVM and native. On wasmJs, a direct call answers when
  the source doesn't suspend and throws `UnsupportedOperationException` when it does.
