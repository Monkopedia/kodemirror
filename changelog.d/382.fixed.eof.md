- Fixed `:lint` diagnostics at the end of the document (#382). A diagnostic whose `to` was past the
  end was stored unclamped, so the next edit threw `Position 8 is out of range for changeset of
  length 5` from the lint state field, and every edit after it threw again. Diagnostics are now
  clamped to the document as `@codemirror/lint` 6.9.5 does: one starting past the end is dropped,
  and one ending past it is cut off at the end but keeps an inclusive end, so text typed there
  extends it. Point diagnostics (`from == to`) also no longer vanish on the next edit. They map
  like upstream's widget: they stay before text inserted at them and are dropped only when a
  deletion spans them.
