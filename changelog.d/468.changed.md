- `IndentContext`, `TreeIndentContext` and `getIndentation` take an optional
  `overrideIndentation: ((DocPos) -> Int)?` (#468), upstream's `IndentContext` option. Given a line
  start, it returns the indentation to report for that line, or -1 for the document's own.
  `lineIndent` and `column` honour it. The constructors' and `getIndentation`'s binary signatures
  change, so callers must recompile.
