- Fixed view plugins leaking when the composition that built them was abandoned (#288). The
  editor builds its plugins while composing, so their first frame already has decorations, but
  only a `DisposableEffect` destroyed them, and an abandoned composition runs no effects; a parse
  worker, linter scope or open LSP file could outlive an editor that never appeared, and the
  session kept pointing at the dead plugin host. The plugin host is now owned by a
  `RememberObserver` that destroys it when the composition is abandoned; an ordinary dispose
  still destroys the plugins first, while the session is attached.
