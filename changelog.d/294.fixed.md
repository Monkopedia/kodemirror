- Fixed input-method composition (#294): Chinese/Japanese/Korean input, emoji pickers and
  Android soft keyboards no longer garble text. The editor's hidden input field was emptied
  after every change, discarding the input method's composing text, so each composition update
  was inserted beside the previous one (`ni` → `nnini`, and Gboard typing `hello` produced
  `hhehelhellhello` on an Android emulator). The field now keeps its text and composition while
  an input method is composing, mirrors the composing range into the document as it changes
  (`input.type.compose`, as in CodeMirror), leaves keys to the input method during a
  composition, and never splits a UTF-16 surrogate pair when diffing.
