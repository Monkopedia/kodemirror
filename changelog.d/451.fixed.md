- Fixed `unifiedMergeView`, which threw during `EditorState.create` for every input (#451). The
  root cause was in `:state`: a `StateField` whose `create` (or `update`) read a field or facet
  listed after it threw "Dynamic slot N was not computed during initialization". Slots are now
  computed on demand while a state initializes, as in `@codemirror/state`, and a cycle between
  fields reports "Cyclic dependency between fields and/or facets". Also in `:merge`, checked
  against `@codemirror/merge` 6.12.0: inline diffs (`allowInlineDiffs`) now mark the inserted
  text rather than an empty range; `diff`/`presentableDiff` no longer throw on lone surrogates;
  and `presentableDiff` aligns to word boundaries using `\p{Alphabetic}`/`\p{Number}` code points,
  so astral letters, Devanagari vowel signs and Roman numerals count as word characters.
